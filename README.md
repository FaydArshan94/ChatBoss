  🛠️ Performance & StateWe moved away from complex context providers and utilized Zustand for global state management.Minimized Re-renders: State updates are granular, ensuring only the necessary components update when a new message arrives.Clean Architecture: Decoupled logic makes the codebase easier to maintain and scale.
